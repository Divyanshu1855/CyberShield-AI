# 🛡️ CyberShield AI

## Intelligent Phishing URL Detection System

CyberShield AI is a web-based cybersecurity application that uses Machine Learning to detect potentially malicious and phishing URLs.

The system analyzes URL features and classifies them as **SAFE** or **PHISHING**. It also provides a risk score and maintains scan history through a dashboard.

---

## 🎯 Objectives

- Detect phishing and malicious URLs using Machine Learning.
- Analyze suspicious URL characteristics.
- Provide a risk score for scanned URLs.
- Maintain URL scan history.
- Provide a simple and user-friendly security dashboard.
- Improve awareness of phishing attacks.

## 🧠 Machine Learning

CyberShield uses a **Random Forest Classifier** to classify URLs.

The current model analyzes features such as:

- URL length
- IP address presence
- HTTPS usage
- Suspicious keywords
